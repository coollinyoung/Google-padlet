# v0.2.0 課堂管理操作與升級

## 升級

先停止伺服器，依 ARCHITECTURE 文件備份 DATA_DIR 與加密金鑰，再執行：

```bash
git pull --ff-only
npm ci
npm run check
npm test
npm start
```

舊有牆會自動視為「使用中、沒有截止時間、每人不限篇數」。原本的 ID、網址、Drive 資料夾與作品都保留，不需要重新建立。Docker 使用者備份 volume 後執行 `docker compose up -d --build`，不要刪除 volume。

## 功能入口

| 功能 | 操作 |
| --- | --- |
| 封存／回收互動牆 | 進入牆 → 管理 → 封存互動牆／移至回收站 |
| 還原互動牆 | 首頁切換「已封存」或「回收站」→ 開啟牆 → 管理 → 還原互動牆 |
| 還原誤刪貼文 | 進入使用中的牆 → 管理 → 貼文回收站 → 還原貼文 |
| 複製教學模板 | 管理 → 複製教學模板 → 輸入新名稱 |
| 設定截止 | 設定 → 截止時間（臺灣時間）→ 儲存 |
| 設定篇數 | 設定 → 每名學生發文上限 → 0～100；0 表示不限 |
| CSV 成果 | 牆上方「CSV 成果」，僅教師可下載 |

封存／回收會停止學生存取，教師仍可閱讀及匯出；需還原牆後才能修改作品。還原保留原有截止與凍結設定。封存不會移除 Drive 資料夾或附件，仍占用容量；本版未實作永久清除。

貼文還原保留內容、留言、反應與附件關聯。啟用審核時，學生作品還原後會重新進入待審；附件尚未完成的草稿保持待完成。

模板副本包含說明、版型、分區、學校網域、審核及每人上限。**不包含學生作品、名單、附件、截止時間或凍結狀態**，適合準備另一個班級；不是完整備份還原功能。

截止時間固定採臺灣時間輸入，後端轉成 UTC；截止後學生不能新增、修改、刪除、上傳、留言或按喜歡。教師可繼續管理。伺服器時間是最終判斷，舊頁面的按鈕即使尚未刷新，送出仍會被拒絕。

發文上限包含未刪除的待審與待上傳作品。刪除可釋出名額；教師還原歷史作品可能使學生現有篇數超過上限，但不會刪除其新作品，也不能再新增。

CSV 只匯出已發布且未刪除的作品文字、作者顯示名稱、分區、時間與計數，不含電子郵件、內部 ID、附件原檔或留言全文。使用 UTF-8 BOM 與引號處理，公式前綴加單引號。教師仍需依用途處理作者姓名。

本版未新增 OAuth scope 或套件依賴。實際 Google 帳號、Drive 與瀏覽器驗收仍需依驗收清單完成。
