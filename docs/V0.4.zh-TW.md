# v0.4.0：投票、貼文排序與延伸底圖

## 更新

先在原本執行程式的終端機按 Ctrl+C，備份原本的 data 或 demo-data 資料夾（含 SQLite 與附件），再於專案資料夾執行：

```sh
git pull --ff-only
npm ci
npm run demo
```

正式環境則使用原本的 `.env` 與 `npm start`。不必刪除既有資料庫；舊牆預設沒有底圖、投票關閉，原貼文順序不變。瀏覽器重新整理後載入新版。

## 20 則影音連結

新增或編輯貼文，在「網址與影音連結」每行貼一個網址，合計最多 20 則。一般網址亦計入此上限；影音仍須按下「載入」才會連線，不會一次自動啟動 20 個播放器。檔案附件仍維持 PNG/JPEG/WebP/PDF 每篇 5 件、每件 10 MB。

## 教師排序

教師按住卡片頂端「拖曳排序」，移至另一篇卡片的上半部或下半部，放開即可插入其前方或後方；也能按 ↑／↓。支援指標事件的滑鼠與觸控裝置。排序儲存到資料庫並透過既有 Drive 快照同步，重新整理保留順序，學生依此瀏覽。

四種版型均使用儲存順序；分欄時拖曳至另一欄的貼文會變更分區。空欄請用「編輯 → 分區」移入。搜尋期間只以可見貼文作為拖曳目標；未顯示的貼文不會刪除。這是卡片排序，不是自由座標畫布。牆面版型沿欄向下排列，網格版型依列排列。

只有牆主教師能改全班順序；封存或回收的牆不能排序。其他人同時更新資料時可能要求重新整理，避免覆蓋變動。進行排序會重新渲染卡片並停止已開啟的播放器。

## 教師底圖

按牆頂端「底圖」，選擇 PNG、JPEG 或 WebP（最多 10 MB），選擇鋪排方式並儲存：

- 重複鋪排：依圖片原尺寸重複，適合無接縫材質圖。
- 符合牆寬：等比例縮放至貼文區寬度，向下重複。

不選新檔案即可更換既有底圖的鋪排方式；勾選「移除目前底圖」可恢復預設。貼文區沒有固定最大高度，底圖隨內容延伸；目前每牆 1,000 篇貼文限制仍存在。「無限延伸」指背景鋪排，不代表無限資料容量，也不會生成新的圖像內容。

正式模式將原圖放入該互動牆 Drive 資料夾的 attachments；示範模式儲存於本機。讀取圖片需要牆面存取權限；學生不會取得 Drive ID 或本機路徑。換圖、移除或衝突後的舊檔仍私有保留，不自動刪除 Drive 原檔。教學模板副本目前不複製底圖，請在新牆重新上傳。

## 貼文投票

教師在「設定」勾選「開啟貼文投票」後儲存。學生點卡片的「投票」；每個帳號在同一面牆最多一票，改投其他卡片會移除原票，再點「已投票」可取消。教師也可投一票。這是對已發布貼文投票，與喜歡功能分開；尚未提供同篇貼文內的問卷選項或多選投票。

所有可讀取貼文的人可看到票數；一般牆面 API 不提供投票人名單。此功能使用登入帳號防重複，並非匿名投票；教師的完整 JSON 備份與私人 Drive 快照包含帳號 ID 與選擇關聯。CSV 只輸出票數。

取消勾選即結束投票，保留結果；重新開啟會沿用原票。截止、凍結、封存及存取權限同樣限制學生投票。貼文回收或重新待審後，其結果不會顯示給無權限的人；原票保留，學生可改投另一篇已發布貼文。模板副本不攜帶投票資料，投票預設關閉。

## 驗證範圍

自動化測試涵蓋 20/21 則邊界、排序與分區、權限、版本衝突、重送、底圖受保護下載、改投／取消、併發投票、審核／截止／凍結。Drive 測試使用模擬服務；尚需在實際學校 OAuth、Drive 與瀏覽器／觸控設備完成驗收。
