# v0.6.0：典雅花紋佈景

教師開啟互動牆，在貼文區上方的「佈景主題」直接點選縮圖按鈕即可切換，無需另按儲存。目前選取的按鈕會顯示「✓ 使用中」。

| 主題 | 配色與圖案 |
| --- | --- |
| 香檳金紋 | 象牙白底、香檳金細線四葉紋 |
| 鼠尾草葉 | 霧綠底、疏落枝葉 |
| 青瓷雅弧 | 青瓷藍底、柔和交錯拱線 |
| 玫瑰織錦 | 灰玫瑰底、菱格與小花紋 |
| 墨金扇影 | 深墨綠底、低對比金色扇形線條 |

五套圖案使用程式隨附的 SVG 向量檔案，簡潔、可重複鋪排，隨貼文區高度延伸。卡片保持淺色，確保文字易讀。手機按鈕自動換行，支援鍵盤 Tab 與 Enter／空白鍵操作。

只有牆主教師可改變全班佈景。切換結果保存於資料庫，再沿用既有 Drive 快照同步。學生會看到相同佈景；若學生正在播放影音，仍沿用原有「新內容」提示，待關閉播放器或重新整理後套用，以免中斷播放。教師切換主題會重繪自身畫面，停止自身開啟的播放器。封存／回收的牆須先還原才能切換。

上傳過的自訂底圖會保留，點「自訂底圖」可切回。上傳新的底圖或變更其鋪排方式會自動啟用自訂底圖；移除自訂底圖會恢復香檳金紋。切換內建主題不刪除原圖片。

新牆預設香檳金紋；舊牆已有自訂底圖則維持原樣。複製教學模板會沿用內建主題；自訂圖片仍需在新牆另行上傳。

更新：停止程式、備份資料後執行 `git pull --ff-only`、`npm ci`，再以 `npm run demo` 或已設定 OAuth 的 `npm start` 啟動，重新整理瀏覽器即可。

已通過 41 項自動化測試，包含主題權限、五套切換與持久儲存、版本衝突、重送、舊底圖及模板相容。已檢視 SVG 渲染結果；實體手機／平板及正式學校 Drive 尚需驗收。
